# GuardLink - run steps (web app)
1. Start MySQL in the XAMPP Control Panel.
2. Open this folder in VS Code and press Ctrl+Shift+B (starts the server).
3. Open http://localhost:8000 in Chrome.
Logins : mary (resident) | guard1 (guard) | manager (management)
## Features
- Residents create digital invitations and send the visitor a registration link
- Visitors register online and receive an entry code and a QR pass
- Guards verify the code at the gate and record check-in and check-out
- The gate page works offline and syncs when the connection returns
- Management sees who is inside, visit history, peak hours, CSV export and the audit log
